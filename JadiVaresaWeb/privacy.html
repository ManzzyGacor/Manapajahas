Kebijakan privasi Varesa

Penjelasan data apa yang kami simpan saat kamu memakai bot WhatsApp dan dashboard Varesa, untuk apa data itu dipakai, dan bagaimana kamu bisa meminta penghapusannya.

Terakhir diperbarui: 15 Oktober 2026 · Versi 1

1. Data yang kami kumpulkan

  • Data akun — id akun, nama, alamat email, dan foto profil dari masuk dengan Google. Kami tidak menerima kata sandi Google-mu.
  • Data bot — nomor WhatsApp yang ditautkan, label bot, status sesi, dan kredensial sesi WhatsApp (dipakai supaya bot tetap tersambung).
  • Data pemakaian — jumlah pesan dan command yang diproses, statistik per bot, dan log teknis singkat. Isi pesanmu tidak dibaca manusia dan tidak ditampilkan di halaman publik; halaman status hanya menampilkan nomor yang disamarkan.
  • Data transaksi — order, paket, nominal, dan status pembayaran. Proses pembayaran dilakukan penyedia pembayaran pihak ketiga; kami tidak menyimpan nomor kartu atau kredensial pembayaran.
  • Data teknis — alamat IP dan informasi perangkat seperlunya untuk keamanan, pencegahan penyalahgunaan, dan menjaga layanan tetap jalan.

2. Untuk apa data dipakai

  • Menjalankan bot kamu: menyambungkan sesi WhatsApp, memproses command, dan mengirim pesan.
  • Mengelola akun, paket, masa aktif, dan tagihan.
  • Menjaga keamanan: mendeteksi penyalahgunaan, mencegah akses tidak sah, dan memenuhi kewajiban hukum.
  • Perbaikan layanan: melihat fitur mana yang sering gagal (statistik per command, tanpa isi pesan) supaya bisa diperbaiki.
  • Membalas pertanyaanmu lewat kanal bantuan.

3. Pesan yang lewat bot

Bot memproses pesan masuk hanya untuk menjalankan perintah — misalnya membaca teks command, mengunduh media yang kamu kirim, atau mengirim balasan. Isi pesan tidak dipakai untuk iklan, tidak dijual, dan tidak ditampilkan ke pengguna lain. Log yang tersimpan bersifat teknis (waktu, command, status) dan dipakai untuk kesehatan sistem.

4. Berbagi ke pihak ketiga

Kami tidak menjual data pengguna. Data hanya dibagikan seperlunya kepada:

  • Penyedia pembayaran — untuk memproses transaksi paket.
  • Penyedia API pihak ketiga — saat kamu menjalankan command yang memang membutuhkannya (mis. pengunduh media). Data yang dikirim hanya yang diperlukan command itu.
  • Penyedia infrastruktur — server tempat layanan ini berjalan.
  • Penegak hukum — kalau diminta secara resmi dan sah menurut hukum yang berlaku.

5. Penyimpanan dan keamanan

  • Kredensial sesi WhatsApp disimpan di server kami dan tidak pernah ditampilkan kembali di dashboard setelah ditautkan.
  • Akses dashboard memakai cookie sesi bertanda tangan dan pemeriksaan ulang di server; token API hanya ditampilkan sekali dan bisa kamu ganti sendiri kapan saja.
  • Kami menyimpan data selama akunmu aktif. Setelah bot atau akun dihapus, data terkait dihapus dari sistem sesuai kebutuhan operasional (termasuk cadangan berkala).

6. Hak kamu

  • Melihat — data akun dan bot kamu bisa dilihat kapan saja di dashboard.
  • Memperbaiki — data yang salah bisa kamu ubah di dashboard, atau minta admin membetulkan.
  • Menghapus — kamu bisa menghapus bot beserta sesi WhatsApp-nya dari dashboard. Untuk menghapus seluruh akun dan datanya, hubungi admin.
  • Keluar dari semua perangkat — tersedia di dashboard, langsung mencabut semua sesi login.

7. Cookie

Situs memakai cookie seperlunya: cookie sesi login (HttpOnly, tidak bisa dibaca skrip halaman) dan penyimpanan lokal browser untuk menandai kamu sudah masuk. Tidak ada cookie iklan atau pelacak pihak ketiga untuk pemasaran.

8. Perubahan kebijakan

Kebijakan ini bisa diperbarui sewaktu-waktu. Versi terbaru selalu ada di halaman ini dengan tanggal pembaruan di atas.

9. Kontak

Pertanyaan atau permintaan terkait data pribadi? Hubungi admin lewat tautan sosial di footer beranda (WhatsApp atau Instagram). Kami membalas pada jam kerja WIB.
