        07 · FAQ
        
Pertanyaan yang sering muncul

        
Belum terjawab? Tanya langsung ke kami lewat WhatsApp.

        Hubungi support
      

      

        

          
          
Bukan. Varesa adalah layanan independen yang menyambungkan nomor kamu lewat fitur Perangkat Tertaut milik WhatsApp — sama seperti saat kamu memakai WhatsApp Web. Kami tidak berafiliasi dengan WhatsApp maupun Meta.

        

        

          
          
Pairing code hanya muncul di dashboard pemilik bot, nomor yang tampil di halaman publik selalu disamarkan, dan isi pesan tidak pernah ditampilkan di mana pun. Kamu juga bisa memutus sesi kapan saja dari menu Perangkat Tertaut di HP.

        

        

          
          
Risiko selalu ada untuk bot yang tidak resmi, terutama kalau dipakai spam. Supaya aman: pakai nomor cadangan khusus bot, jangan kirim pesan massal ke orang yang tidak dikenal, dan biarkan nomor baru dipakai normal beberapa hari dulu sebelum ramai.

        

        

          
          
Ya. Bot berjalan di server kami, jadi tetap aktif walau HP kamu mati atau sedang tidak ada internet. Kalau sesi terputus (misalnya logout dari HP), cukup tekan Start lagi di dashboard dengan nomor yang sama.

        

        

          
          
Masuk dengan Google, isi nomor bot di dashboard lalu tekan Start. Setelah pairing code muncul, buka WhatsApp › Perangkat Tertaut › Tautkan perangkat › Tautkan dengan nomor telepon saja, lalu ketik kodenya.

        

        

          
          
Bisa. Setiap bot punya token API di dashboard. Kirim POST /api/v1/text atau /api/v1/image dengan header x-varesa-token. Kuota harian ikut paket: Free 50, Core 1.000, Prime 5.000, Zenith 20.000 pesan. Lihat contoh kode.

        

        

          
          
Bot yang sudah aktif tetap berjalan seperti biasa. Hanya sesi baru yang ditahan sampai ada slot kosong. Sisa slot ditampilkan langsung di bagian Kapasitas server dan halaman Status, jadi kamu bisa cek kapan tersedia lagi.
