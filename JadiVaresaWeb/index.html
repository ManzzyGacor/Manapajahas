Tiga langkah sampai bot menyala

Rata-rata selesai di bawah dua menit, selama nomor kamu bisa menerima kode dari WhatsApp.

  1. 1

    Masukkan nomor

    Ketik nomor WhatsApp yang mau dijadikan bot di dashboard, lalu tekan Start.

    628xxxxxxxxxx
  2. 2

    Tautkan perangkat

    Pairing code muncul di terminal. Buka WhatsApp, masuk ke Perangkat Tertaut, pilih tautkan dengan nomor telepon.

    K7F2-9QLM
  3. 3

    Atur dan jalankan

    Pilih mode publik atau khusus grup, isi balasan otomatis, dan bot langsung bekerja.

    status: aktif

Yang bisa kamu atur

Semua diatur dari dashboard. Tidak ada file konfigurasi yang perlu disentuh.

Balasan otomatis

Tentukan kata kunci dan jawabannya. Bot membalas tanpa perlu diawali titik, cocok untuk pertanyaan yang itu-itu saja.

Menu buatan sendiri

Susun ulang isi menu bot, lengkap dengan sapaan, nama pengirim, dan tanggal yang terisi otomatis.

Beberapa nomor owner

Daftarkan rekan kamu sebagai owner supaya mereka bisa memakai perintah khusus admin.

Mode publik atau grup

Batasi bot hanya menjawab di grup, atau biarkan terbuka untuk chat pribadi juga.

Terminal langsung

Lihat log bot mengalir waktu nyata, termasuk saat pairing code keluar dan sesi terputus.
