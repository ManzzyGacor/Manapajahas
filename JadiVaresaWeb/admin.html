Penjaga kapasitas

Berapa bot yang muat di server ini. Dihitung dari RAM & CPU asli.

Saat slot habis, user tidak bisa menyalakan bot BARU (restart bot yang masih hidup tetap boleh, admin selalu boleh). Ini mencegah RAM jebol sampai semua bot ikut mati.

Cara menghitungnya

Angka asli dari server ini.

  1. Batas RAM — diambil yang terkecil antara RAM mesin/container dan batas PM2 (max_memory_restart, bawaan 1200 MB). Lewat dari batas PM2, proses di-restart dan semua bot ikut putus.
  2. Sisihkan cadangan (persen yang kamu atur) untuk lonjakan, lalu kurangi RAM dasar aplikasi saat belum ada bot.
  3. Bagi rata-rata RAM per bot — diukur dari bot yang sedang jalan → kapasitas dari RAM.
  4. CPU ikut membatasi: ±25 bot per core.
  5. Batas admin (kalau diisi) ikut dibandingkan. Angka terkecil yang dipakai, jadi batas admin tidak bisa membuat server kelebihan beban.
